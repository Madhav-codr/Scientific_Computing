# Scientific Computing

**Bridging computation and fundamental science through visualization and numerical methods.**

---

## 📌 Overview

This repository focuses on applying computational techniques to explore and understand core concepts in the physical sciences. It emphasizes **visualization**, **numerical solutions**, and **intuitive understanding** of mathematical and scientific models.

---

## 🎯 Objectives

* Develop numerical solutions to fundamental scientific problems
* Visualize abstract concepts for deeper intuition
* Explore computational approaches to physics and mathematics
* Build a structured collection of reproducible scientific notebooks

---

## 🧪 Topics Covered

* First Order Ordinary Differential Equations (ODEs)
* Probability and Distribution Laws in Quantum Physics
* Numerical methods
   
---

## 🛠️ Tech Stack

* Python
    * numPy
    * matplotlib
    * scipy
    * adjustText
    * molmass
* Jupyter Notebook

## 🚀 Getting Started

### 1. Clone the repository

```
git clone https://github.com/Madhav-codr/Scientific_Computing.git
cd Scientific_Computing
```

### 2. Install dependencies

```
pip install scipy numpy matplotlib jupyter
```

### 3. Run notebooks

```
jupyter notebook
```
