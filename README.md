# Scientific Computing

A collection of notebooks and experiments focused on **scientific computing**, with an emphasis on **visualization** and **numerical solutions** to problems from fundamental sciences.

---

## 📌 Overview

This repository explores computational approaches to understanding concepts from:

* Quantum Mechanics
* Differential Equations
* Mathematical Physics
* Probability & Distribution Laws

Using Python and Jupyter notebooks, the goal is to bridge theory with **visual intuition** and **practical implementation**.

---

## 🎯 Objectives

* Visualize abstract scientific concepts
* Solve mathematical models numerically
* Build intuition through simulations
* Provide clean, reproducible computational examples

---

## 🧪 Topics Covered

* Solutions of Ordinary Differential Equations (ODEs)
* Distribution laws and statistical visualization
* Introductory Quantum Mechanics simulations
* Numerical methods and approximations

---

## 🛠️ Tech Stack

* Python
* Jupyter Notebook
* NumPy
* Matplotlib / Plotting libraries

## 🚀 Getting Started

### 1. Clone the repository

```
git clone https://github.com/your-username/Scientific_Computing.git
cd Scientific_Computing
```

### 2. Install dependencies

```
pip install numpy matplotlib jupyter
```

### 3. Run notebooks

```
jupyter notebook
```
